# Alpha Driving Academy

Production static site for Alpha Driving Academy (CDL training in Pantego, TX) — `cdlalphadrivingschool.com`.

Plain HTML/CSS/JS, no build step, no external runtime dependency (only Google Fonts over the network). Bilingual EN/ES, tabbed mobile-app-style layout, 3-step enrollment flow that hands off to WhatsApp (no backend), FAQ, and an on-page canned-answer chat widget.

## Files
- `index.html` — markup + inline styles + SEO meta/JSON-LD
- `app.js` — all interactivity and the EN/ES content dictionary
- `assets/` — logo, hero photo, favicons
- `robots.txt`, `sitemap.xml`, `manifest.webmanifest`

## Deploy
Upload the contents of this repo as-is to any static host (GitHub Pages, Netlify, etc.) at the `cdlalphadrivingschool.com` domain. No build step required.
